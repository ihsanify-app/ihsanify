# Experiment: [title]

Template for recording a before/after measurement. Copy this file to a new,
descriptively-named file per experiment (e.g. `invoice-list-n-plus-1.md`).

## Question / hypothesis

What was being tested, and what was the expected outcome before running it?

## Dataset

Size of the dataset used, and how it was generated (seed script, command,
source of the data).

## Test conditions

Environment the test ran in, and the exact command(s) used to run it —
enough detail that it could be reproduced later.

## Results before

The baseline measurement, before any change.
